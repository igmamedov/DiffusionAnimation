# Image-to-Video Diffusion Models for Animating Human Images

Выполнил: Мамедов Ильгар Габилович

Научный руководитель: Лисов Роман

## Информация о работе:

Данный проект выполнляся в рамках курсовой работы на Факультете компьютерных наук НИУ ВШЭ, программе ФТиАД. В рамках исследования изучался вопрос о генерации видео с участие человека в Ecom индустрии

## Навигация по репозитоию:

__Moore-AnimateAnyone__ - модифицированеая реализация [статьи](https://arxiv.org/pdf/2311.17117) компанией [Moore Threads](https://en.mthreads.com/product/S80)

__dataset__ - данные используемые в исследовании

__modules__ - дополнительные необходимые модули для исследования

__notebooks__ - аналитика

__test_examples__ - примеры генераций
